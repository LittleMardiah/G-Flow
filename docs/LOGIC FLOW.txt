1.1 WALLET LIFECYCLE
────────────────────────────────────────────────────────────────────────────────

STATE MACHINE:
  [CREATED] → [ACTIVE] ←→ [SUSPENDED] ←→ [FROZEN] → [DELETED]

BEHAVIOR BY STATE:
  ACTIVE:      Can send/receive money, make orders
  SUSPENDED:   Cannot send/receive, pending review (balance frozen)
  FROZEN:      Cannot do anything (investigation in progress)
  DELETED:     Account completely removed (30-day grace period)

     → Allow mutation, set is_late_settlement = TRUE
     → Alert admin for reconciliation

  ❌ Overdue Debt settlement (Bug #47):
     → Top-up amount goes to debt first
     → Only remainder goes to wallet
