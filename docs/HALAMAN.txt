📌 OVERVIEW
================================================================================

Dokumen ini berisi **wireframe (blue-print) UI** untuk semua user roles dalam G-Flow:
- 🧑 **Customer** — Memesan ride, food, package
- 🚗 **Driver** — Accept orders, complete delivery
- 🍴 **Merchant** — Manage catalog, process orders
- 👨‍💼 **Admin** — Monitor ledger, manage disputes

**Design Principles:**
- ✅ Mobile-first (responsive design, min-width 360px)
- ✅ Accessibility (WCAG 2.1 AA standard)
- ✅ Dark mode support (optional for V1.1)
- ✅ Offline capability (cache critical flows)
- ✅ Performance: Cold start < 3s, interactions < 300ms
- ✅ 100% SYNCHRONIZED WITH BACKEND: All UI components map to API endpoints and database schema

**Platform:** Flutter (cross-platform native) + React Web (admin panel)

FIXES APPLIED (v2.0-FINAL — Based on Gemini Review v1.0):
  1. ✅ G-Send Multi-Stop Fare Breakdown: Added allocated_fare per stop
  2. ✅ G-Send Return-to-Sender UI: Added RETURN_REQUIRED and RETURNED_TO_SENDER flows
  3. ✅ G-Food Multi-Group Variant Options: Added merchant_item_option_groups UI
  4. ✅ G-Food Menu Versioning Fallback: Added version mismatch warning modal
  5. ✅ Driver KYC Validation: Added SIM, license expiry, plate, min_balance_threshold
  6. ✅ Merchant Status Transition: Added PENDING_VERIFICATION to ACTIVE indicator
