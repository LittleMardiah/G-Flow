E. INFRA / MIGRATION - Known limitations tooling migrasi database (PostgreSQL /
   golang-migrate): statement yang butuh auto-commit (di luar transaction block)
-------------------------------------------------------------------------------

ID                    : TD-035
Kategori              : INFRA
Judul                 : Migration 010 (`010_admin_lockouts.up.sql`) berisi
                        `ALTER TYPE wallet_type_enum ADD VALUE` di file yang
                        sama dengan CREATE TABLE yang pakai value tersebut.
